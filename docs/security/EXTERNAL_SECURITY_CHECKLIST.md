# External security checklist

All items below are **Pending Manual Action** unless marked otherwise. No external configuration
has been verified. Mandatory means required for a public production deployment in the stated topology.
Keep recovery console access and config backups before changes; never submit credentials to chat.

| Provider / requirement | Exact steps and required access | Mandatory / cost | Benefit and verification | Rollback |
|---|---|---|---|---|
| Cloudflare account | Account owner: enable MFA, secure recovery codes, invite least-privilege operators | If using Cloudflare; plan dependent | Limits account takeover; verify second operator/recovery access | Restore reviewed roles; retain MFA |
| Cloudflare zone/DNS | DNS admin: export zone; add domain; reconcile every record; change registrar NS; coordinate DNSSEC DS | If migrating; free zone options | Proxied web DNS; verify NS, A/AAAA and mail delivery | Restore saved NS/DS with TTL planning |
| Cloudflare TLS | Zone admin + host operator: install valid matching origin certificate; select Full (strict); verify HTTPS then redirect edge HTTP | Required for direct origin; certificate costs vary | Encryption and origin authentication; inspect chain and redirect behavior | Restore previous valid cert/config; never use Flexible as shortcut |
| Cloudflare WAF/rates/bots | Security admin: enable available rules; set /api/ rate thresholds from usage; observe events; test API/SSE and admin clients | Required abuse controls; advanced rules/bots paid | Reject malicious traffic; verify controlled 429 and legitimate calls | Disable only offending rule, retain application controls |
| Cloudflare Access | Zero Trust admin: create IdP policy for admin path/hostname; test browser and machine identities | Optional; separate service/user limits | Extra admin identity boundary; verify denied unauthenticated access | Disable Access policy only after app admin auth is verified |
| Cloudflare caching | Cache admin: bypass /api/*, Authorization and errors; remove conflicting Cache Everything rules | Required; available controls vary | Prevents private cache leaks; compare two workspace keys and cache headers | Restore conservative bypass, purge accidental cached private objects |
| Cloudflare origin isolation | Host + zone admins: choose Tunnel or current IPv4/IPv6 allowlists with AOP; apply only after recovery/test | Required when Cloudflare protects origin; host/service costs vary | Blocks direct bypass; test own origin Host request from outside trusted path | Restore saved firewall/cert config through console |
| Cloudflare Tunnel | Zero Trust + host admin: create named tunnel; store credential outside repo; fill templates; pin image digest; route hostname; verify connector and catch-all | Optional alternative to direct origin; service plan terms apply | Removes inbound origin requirement; verify ports closed and public app works | Stop connector and restore verified prior ingress/DNS |
| Registrar privacy | Registrar owner: enable eligible WHOIS/RDAP privacy/redaction; inspect lookup; keep accurate underlying data and verification | Privacy optional; TLD/registrar fees vary | Reduces personal public fields; inspect RDAP and forwarding contact | Disable service if needed while retaining accurate details |
| Registrar account | Owner: MFA, registrar lock, renewal/expiry alerts, recovery/business email | Required; lock tiers may cost | Prevents hijack/expiry; verify renewal/contact confirmation | Restore access via registrar recovery |
| DNS provider leak review | DNS admin: audit A/AAAA/CNAME/MX/TXT/SPF, staging and stale records; separate mail from origin; assess historical records | Required; migration may cost | Removes current origin references; compare full exported zone/public answers | Restore necessary records from backup |
| Hosting ingress/TLS | Host admin: retain console/VPN; bind frontend loopback; expose only audited TLS ingress or Tunnel; close DB/Redis/API host ports; configure allowed hosts/proxy CIDRs | Required; host/firewall costs vary | Limits origin and admin attack surface; inspect listeners and own-host tests IPv4/IPv6 | Console restore saved ingress/firewall rules |
| Hosting HTTPS/HSTS | Host + edge admin: test end-to-end scheme; set enforcement; verify no loops; enable HSTS last | HTTPS required; HSTS optional after readiness | Protects transport; HTTP must reject/redirect at edge, HTTPS succeeds | Disable config; HSTS persists in clients until expiry |
| Hosting secrets/backups | Host operator: provision env from secret storage, chmod/ACL files, rotate exposed keys, encrypted off-host backups and restore drill | Required; storage costs vary | Reduces secret/data loss risk; verify secret ACL and isolated restore | Restore previous encrypted backup/config, revoke compromised keys |
| Hosting logs/monitoring | Operator: disable raw access/query/body logging at every hop; apply retention, access controls, alert on auth failures/429/5xx without storing keys | Required; tooling costs vary | Detects abuse with less PII; inspect redacted sample and retention deletion | Restore safe diagnostic verbosity, never raw secrets |
| Hosting release scans | Operator: pin approved image digests, scan images/dependencies, run staging regression including browsers, verify .map blocked | Required; scanner/CI costs vary | Detects vulnerable artifacts; retain scan and staging evidence | Redeploy previous verified images/migration-compatible release |
| Email provider | Mail admin: dedicated business mailbox/support channels, MFA, SPF/DKIM/DMARC staged enforcement; retain MX DNS-only | If used; provider dependent | Separates personal identity and reduces spoofing; delivery/auth checks | Restore prior mail policy from backup |
| Payment provider | No payment integration found | **Not Applicable** currently | Reassess business descriptors, receipts, webhooks and lawful KYC if added | Not applicable |
| Business/legal | Authorized business owner/adviser: verify mandatory company/contact/privacy disclosures and lawful business address; review public CMS/media | Required where applicable; advisory/service fees vary | Truthful compliance with less unnecessary PII; review rendered public pages | Restore previous compliant disclosure |
