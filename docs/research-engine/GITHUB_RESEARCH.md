[SearXNG's search API](https://docs.searxng.org/dev/search_api.html) supports JSON when enabled. [Its upstream initialization issue](https://github.com/searxng/searxng/issues/6584) illustrates availability coupling to search engines. [Vane's connector discussion](https://github.com/youdotcom-oss/integration-tracking/issues/62) illustrates provider coupling. Inspect provider responses and handle degraded or empty results explicitly.

[Brave](https://api-dashboard.search.brave.com/api-reference/web/search/get) is a credentialed independent index. [Tavily](https://docs.tavily.com/documentation/api-reference/endpoint/search) and [Exa](https://docs.exa.ai/reference/search) return search results with service-specific enrichment. [Serper](https://serper.dev/) offers Google result data. Adbot uses search results for discovery and retrieves evidence independently. Provider defaults favor self-hosting and make paid access opt-in.

No upstream implementation is vendored. Trafilatura is installed as an Apache-2.0 dependency. Pycountry (LGPL-2.1-only) supplies ISO country and currency codes. React Markdown and remark-gfm (MIT) render the research output. SearXNG runs as a separate AGPL-3.0 deployment with its own license and redistribution obligations.
